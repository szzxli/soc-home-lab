How the detectors work

unusual_geo Successful ConsoleLogin from an IP outside a tiny built-in table of common ranges — demo heuristic only, a production system should use a real GeoIP database (e.g. MaxMind GeoLite2).

brute_force ≥ N failed ConsoleLogin attempts from one IP inside a sliding window (default 5 in 10 min) — one finding per IP, earliest window wins.

suspicious_api Watchlist of high-risk API calls: PutUserPolicy, AttachUserPolicy, AttachRolePolicy (high), CreateAccessKey / RunInstances (medium), DeleteTrail / StopLogging (high).

On the noisy sample these rules fire on autoscaling, key rotation, CI deploys, travelling employees and a shared office NAT. That's expected. NOISY_DATA.md explains each false positive and how to tune it.

AbuseIPDB enrichment is skipped in this browser build — exactly like the CLI behaves without an ABUSEIPDB_API_KEY set.
