ATT&CK Navigator layer

This page publishes a MITRE ATT&CK Navigator layer for soc-home-lab. The layer includes only technique IDs that already appear in shipped lab artifacts. It is a map of cited lab coverage, not a claim of job readiness, professional certification, or complete ATT&CK coverage.

Download layer JSON Open in ATT&CK Navigator

What is in the layer

Each technique below is cited by ID in the named shipped artifact. Techniques are not added from lab titles, tactic names, or nearby prose.

  • T1190 — cited by Sigma tag attack.t1190 in 08-nodered-flow-audit/detect/nodered-post-flows.yml.
  • T1059 — cited by Sigma tag attack.t1059 in 08-nodered-flow-audit/detect/nodered-exec-tmp-write.yml.
  • T1059.004 — cited in 07-kev-hunting/detect/php2shell-wazuh-rules.xml, Wazuh rules 100100 and 100110.
  • T1105 — cited in 07-kev-hunting/detect/php2shell-wazuh-rules.xml, Wazuh rule 100101.
  • T1505.003 — cited in 07-kev-hunting/detect/php2shell-wazuh-rules.xml, Wazuh rule 100102.

What is not in the layer

Labs and artifacts that do not cite a technique ID are left out. Tactic-only mentions are not converted into technique IDs, and untagged detection rules are not assigned techniques here. If a shipped artifact later cites a technique ID, the layer can be updated from that citation.

Use it

Download the JSON and open it with the Navigator's existing-layer loader, or use the open button above. The layer file is served from this site at layers/soc-home-lab.json.
